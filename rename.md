# ACC102 Track 2 - US Tech Stock Analysis

## 1. Project Purpose
This project analyzes the stock price trends and return risks of four major US tech companies in 2023.

## 2. Data Source
Yahoo Finance (AAPL, MSFT, GOOGL, AMZN)
Period: 2023-01-01 to 2024-01-01

## 3. Methods Used
- Data collection
- Data cleaning
- Return calculation
- Visualization
- Risk & return analysis

## 4. Key Findings
- AAPL has the highest average return
- AMZN has the highest volatility (risk)
- All stocks showed similar market trends in 2023

## 5. How to Run
Run the acc102_stock_analysis.ipynb file directly.
